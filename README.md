# Italian Restaurant 🍝🛒

Italian Restaurant is a web application for browsing a restaurant menu and placing food orders online.  
The app allows users to explore dishes by category, manage a shopping cart, and dynamically update orders.

## 🚀 Features

- Browse restaurant menu with categories and dishes  
- Filter dishes by selected category  
- Add dishes to the shopping cart  
- Real-time cart updates and total price calculation  
- Responsive and clean user interface  

## 🛠 Tech Stack

- **Frontend:** Next.js, React, TypeScript  
- **Styling:** Tailwind CSS, shadcn/ui  
- **State Management:** React Context API & Hooks  
- **Backend / API:** Next.js API Routes  
- **Database:** Supabase  

## 📦 Installation & Run

```bash
git clone https://github.com/kanterete/corvo-bianco-italian-cuisine
cd corvo-bianco-italian-cuisine
npm install
npm run dev
```
